# i18n_data.lua

Generated MIT glass catalog data.

Generated by python tools/glass_i18n.py build from glass/i18n/*.po using the companion parser/escaping. Included by i18n.lua and returns a language-to-phrase table. Do not hand edit. No side effects, files or networking.

This is a runtime Lua module, not a process: it has no exit code. Engine/load errors propagate to the caller. See the glass README for the full setting and frame contract.
