# i18n.lua

MIT glass language lookup, following the companion or game language.

Client include loads generated i18n_data.lua. Language follows nonempty nativeloader_language, otherwise gmod_language; zh and zh-tw aliases are accepted. L returns translated text or English; Phrase registers a stable GMod language key. No file or network mutations.

This is a runtime Lua module, not a process: it has no exit code. Engine/load errors propagate to the caller. See the glass README for the full setting and frame contract.
