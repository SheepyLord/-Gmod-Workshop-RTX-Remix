# gmapack.bat

Drag-and-drop wrapper for [`gmapack.py`](gmapack.py.md): drop a folder on it to pack it, or a `.gma`
to extract it. With no argument it shows the help. It runs `python`, falling back to the `py -3`
launcher, then pauses so the window stays open to read the result.

Part of the vendored GMA File Packer; not used by scripts in this repo.
