# test_game_activity.py

Generated policy cases for the R12 launch gate: no field process, foreground ownership,
recent input, the exact ten-minute boundary, an idle field and unknown process paths.
Run from `tools/`: `python -m unittest tests.test_game_activity` or normal discovery.
No Windows process/window/input API is called by these tests. No files, game or network touched.
Exit 0 pass, nonzero failure.
