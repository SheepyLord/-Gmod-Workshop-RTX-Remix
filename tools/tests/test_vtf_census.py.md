# test_vtf_census.py

Generated VTF header cases test exact logical bytes and mip accounting, short/extra image data,
unsupported version/format/frame/depth and invalid dimensions/mips. Run from `tools/` with
`python -m unittest discover -s tests -p test_vtf_census.py`. No file, game, install or network
access. Exit 0 pass, nonzero failure.
