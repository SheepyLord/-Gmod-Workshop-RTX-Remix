# loader/guard/tests

`test_early.cpp` exercises the production `guard::append_client_guard` and `guard::prepare`
functions using generated initializer, Lua guard and module bytes in synthetic game folders under
the test executable's scratch directory. `CMakeLists.txt` builds `nl_render_guard_tests` with the
existing `loader/tests/test_main.cpp` / `nl_test.h` harness and registers its 120-second CTest.

The positive fixture explicitly supplies its generated initializer's hash. No Steam initializer,
game binary, GPL addon source, user configuration or network service is used. A separate test calls
the default production hash policy and requires it to reject those generated bytes.

Coverage includes client-only local scope and protected-call text, the local-view proof (the early
flag and guard only past a `file.Exists(<cache file>, "BASE_PATH")` check naming the cache file
itself; proof paths that are not plain relative paths are refused), exact original-byte
preservation, verified guard selection, input-named cache files (a changed guard or initializer
gets a new name, the old file untouched), idempotence, disabled/missing policy, allowlist and owner
rejection, source/module tampering, missing marker, NUL and initializer size limits, and failures as
plain exceptions (start-up keeps RTX and notes them, ADR 0056). A changed cache file, or a folder
in its place, is moved to `native-loader/backup/render-guard/<name>.<n>` with its bytes intact and
the view written again; a junction there is refused without touching the changed cache. Foreign
selected runtimes perform no reads or cache writes. Junction cases cover the stock initializer,
verified guard source, cache directory and kept-copy folder. They are skipped if the platform
refuses to create a generated junction; cleanup removes the junction itself without following its
target.

The append tests inspect the emitted Lua contract; this C++ executable does not execute Lua or
establish in-game behavior. GPU/game acceptance is separate.

After configuring the aggregate build, build `nl_render_guard_tests`, then run
`ctest --test-dir <build-directory> -R ^nl_render_guard_tests$ --output-on-failure`.
